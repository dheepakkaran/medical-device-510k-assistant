# Failures and limits (from the real runs)

1. **The keyword baseline beat embedding search.** On the 20 frozen questions, Postgres full-text keyword search found the gold page in the top 3 for 16/20, embeddings (bge-small) for 14/20, and the hybrid (RRF) for 14/20. FDA guidance repeats exact regulatory phrases ("Truthful and Accuracy Statement", "Declaration of Conformity"), which favours keywords. The app default was fixed as hybrid before the test run and was not changed after seeing the result; switching to keyword would be choosing on the test set.
2. **Gold labels were too strict for checklist items.** q07 (Truthful and Accuracy Statement) and q09 (Declaration of Conformity) were labelled with one page, but the same checklist item repeats in the Traditional, Abbreviated and Special 510(k) appendices (pages 26/63/95 and 30/50/60/86/97). The model cited a correct copy on another page (p95, p60), which the strict score counts as a miss. The frozen file was not edited; with those two counted, 17/20 answers cite a correct page.
3. **Retrieval caps accuracy, not the model.** For q04, q07 and q09 the gold page was not in the 5 passages at all. Opus 5.5 on q01–q10 cited the gold page exactly as often as the Haiku cascade (5/10) at about 41x the cost.
4. **One honest "not found".** q02 (reference devices) was retrieved at rank 4 but Haiku answered `found: false`; the cascade only escalates on a failed quote check, not on "not found", so Opus never saw it. A next step is to escalate "not found" when retrieval scores are high.
5. **The escalation path never fired on the test set.** Haiku's quotes passed the word-for-word check 20/20 times. The escalation logic is covered only by unit tests with a fake model (`tests/test_routing.py`).
6. **Small, hand-written test set.** 20 questions written by one person from 3 guidance PDFs; no second labeller. Numbers are a sanity check, not a benchmark.
7. **"Draft predicate table" is a filter, not a judgement.** Candidates are earlier clearances with the same product code; the app does not compare intended use or technology. The page says a human must confirm both.
8. **Docker files are written but were not run in the build session** (the session could not reach the Docker socket); the local run used PostgreSQL 18 + pgvector from conda-forge via pixi (`scripts/db.sh`).
